# 🎮 unity_CreateWithCode

Welcome to **unity_CreateWithCode**! This repository is a beginner-focused game development module built using the **Unity 6 Engine** and **C#**. 

Whether you are just starting your journey into game development or looking to brush up on the fundamentals of the Unity ecosystem, this project serves as a practical, hands-on learning resource. 

---

## 📖 About This Project

This module is designed to introduce the core concepts of game development in Unity 6. Instead of overwhelming beginners with complex architecture, it focuses on building a solid foundation. By exploring the code and scenes in this repository, you will understand how objects interact, how to write clean C# scripts, and how to utilize Unity's built-in physics and rendering systems.

## ✨ What You Will Learn (Features)

*   **C# Scripting Fundamentals:** Variables, methods, loops, and conditional statements.
*   **Player Input & Movement:** Reading keyboard/controller inputs to move characters and objects fluidly.
*   **Physics & Collisions:** Utilizing `Rigidbodies` and `Colliders` to create realistic interactions and detect triggers.
*   **Prefabs & Instantiation:** Spawning and destroying objects (like enemies or projectiles) dynamically at runtime.
*   **Basic UI (User Interface):** Displaying text, scores, and basic menus on the screen.
*   **Scene Management:** Transitioning between menus and gameplay levels.

## 🛠️ Prerequisites

To run this project on your local machine, you will need the following installed:

*   **Unity Hub & Unity 6:** Make sure you install the Unity 6 engine (Version `6000.0.x` or newer).
*   **Code Editor:** [Visual Studio 2022](https://visualstudio.microsoft.com/) or [Visual Studio Code](https://code.visualstudio.com/) (with the Unity extension).
*   **Git:** To clone the repository.
